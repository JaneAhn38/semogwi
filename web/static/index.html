    0 / 30자
    콘텐츠 유형 필수
    제작 방식
    AI가 조사할 때 함께 읽고, 카드에는 사용자 제공 자료로 표시돼요. 자동 접근이 금지된 사이트의 내용도 여기에 붙여 넣으면 돼요.
    올리면 오른쪽에서 배경 제거와 사용 권한을 정할 수 있어요.

    왼쪽에 주제를 적고 시작해 보세요

    이미지를 올리면 여기에서 배경을 제거하고 원본과 비교할 수 있어요.

    이미지 준비

    올렸다고 사용 허가가 되는 건 아니에요. 허가됨으로 고른 이미지만 카드에 쓸 수 있어요. 원본은 그대로 보관돼요.

    제작 진행 상태

    데모 시뮬레이션 실제 AI

      자료 직접 입력

      사용자 제공 자료로 표시돼요

        입력한 내용은 AI가 공식 페이지에서 확인한 것으로 표시되지 않고, 카드 출처에도 사용자 제공으로 남아요. 모르는 항목은 비워 두세요. AI가 지어내지 않아요.

        자료 조사 결과

        실제 조회 기록과 대조해 표시해요. 페이지 읽음만 확인된 출처이고, 검색 목록에만 있는 주소는 확인된 출처가 아니에요. 문장이 페이지와 맞는지와 이용 조건은 직접 확인해 주세요.

        조사 항목

        카드 5장에 필요한 항목이에요. 공식 확인과 2차 자료는 그 페이지를 실제로 읽은 것이고, 나머지는 카드에 쓰기 전에 확인이 필요해요.
