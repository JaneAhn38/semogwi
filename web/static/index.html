    어떤 카드뉴스를 만들까요?

    0 / 30자
    콘텐츠 유형 필수
    제작 방식
    자료 조사 방식
    AI가 조사할 때 함께 읽고, 카드에는 사용자 제공 자료로 표시돼요. 자동 접근이 금지된 사이트의 내용도 여기에 붙여 넣으면 돼요. '공식 출처'를 골라도 AI가 확인한 공식 자료로 표시하지 않아요. 나무위키 자료는 캐릭터 소개의 성격·친구·가족·TMI에만 보조 출처로 써요.
    올리면 오른쪽에서 배경 제거와 출처를 정할 수 있어요.

    왼쪽에 주제를 적고 시작해 보세요

    이미지를 올리면 여기에서 배경을 제거하고 원본과 비교할 수 있어요.

    이미지 준비

    올린 이미지는 바로 카드에 쓸 수 있어요. 출처를 적어 두면 함께 저장돼요. 원본은 그대로 보관돼요.

    제작 진행 상태

    데모 시뮬레이션 실제 AI

      자료 직접 입력

      사용자 제공 자료로 표시돼요

        입력한 내용은 AI가 공식 페이지에서 확인한 것으로 표시되지 않고, 카드 출처에도 사용자 제공으로 남아요. 모르는 항목은 비워 두세요. AI가 지어내지 않아요.

        상세페이지 이미지 (자료 조사용)

        카드에는 넣지 않아요

        쇼핑몰 상세 설명이 글이 아니라 이미지로 되어 있으면 자동 조사가 읽지 못해요. 상세페이지 스크린샷이나 이미지 파일을 올리면 AI가 상품명·가격·크기·소재·구성품·판매 기간·특징을 읽어요. 흐리거나 잘린 글자는 추측하지 않고 확인 필요로 남겨요.
