# 세모귀 카드뉴스 템플릿 레이어 문서

> **세모귀 (세상의 모든 귀여운 것들)**
> Claude Code를 이용한 캐릭터 카드뉴스 자동화 프로젝트

---

## 1. 템플릿 개요

| 항목 | 내용 |
| --- | --- |
| 프로젝트명 | 세모귀 (세상의 모든 귀여운 것들) |
| 목적 | 캐릭터 카드뉴스 제작 자동화 |
| 디자인 도구 | Figma Design |
| 자동화 도구 | Claude Code |
| 캔버스 크기 | 1080 × 1350 px (4:5 세로형) |
| 템플릿 수 | 5장 (`card-01` ~ `card-05`) |
| 제목 폰트 | Jua |
| 본문 폰트 | Gowun Dodum |
| 배경 | 파스텔 그라데이션 |

---

## 2. 레이어별 역할

| 레이어명 | 역할 | 유형 | 자동화 여부 |
| --- | --- | --- | --- |
| `title` | 카드별 제목 | 텍스트 (Jua) | ✅ 자동화 대상 |
| `body` | 카드별 본문 | 텍스트 (Gowun Dodum) | ✅ 자동화 대상 |
| `main-image` | 캐릭터 이미지 | 이미지 | 🔜 추후 자동화 대상 |
| `page-number` | 페이지 번호 | 텍스트 | ⏸ 현재 고정 |
| `source` | 카드별 자료 출처 | 텍스트 | ✅ 자동화 대상 |
| `bottom-overlay` | 하단 그라데이션 | 도형 / 그라데이션 | 🔒 고정 |

### 레이어 상세

- **title**
  - 각 카드의 핵심 메시지를 담는 제목 텍스트입니다.
  - 폰트: Jua
  - 자동화 시 텍스트 길이에 따른 줄바꿈·넘침 여부를 확인해야 합니다.

- **body**
  - 제목을 보충하는 본문 텍스트입니다.
  - 폰트: Gowun Dodum
  - 문장 길이가 카드마다 다르므로 최대 글자 수 기준을 정해 두는 것이 좋습니다.

- **main-image**
  - 카드의 중심이 되는 캐릭터 이미지입니다.
  - 현재는 수동으로 배치하며, 추후 이미지 경로 또는 URL을 받아 교체하도록 자동화할 예정입니다.

- **page-number**
  - 카드 순서를 표시합니다 (예: 1/5).
  - 현재는 프레임별로 고정된 값을 사용합니다.

- **source**
  - 카드에 사용된 자료의 출처를 표시하는 텍스트입니다 (예: `출처: ○○○`).
  - 카드마다 출처가 다를 수 있으므로 자동화 대상으로 둡니다.
  - 출처가 길어질 수 있으므로 최대 글자 수와 줄바꿈 기준을 정해 두는 것이 좋습니다.

- **bottom-overlay**
  - 하단 텍스트 가독성을 높이기 위한 그라데이션 레이어입니다. 모든 카드에서 동일하게 유지됩니다.

---

## 3. 프레임 구조

5개 프레임은 모두 같은 레이어 구성을 따릅니다.

```
card-01 ~ card-05  (Frame, 1080 × 1350)
├── title            # 제목 (Jua)              — 자동화
├── body             # 본문 (Gowun Dodum)      — 자동화
├── main-image       # 캐릭터 이미지           — 추후 자동화
├── page-number      # 페이지 번호             — 현재 고정
├── source           # 자료 출처               — 자동화
└── bottom-overlay   # 하단 그라데이션         — 고정
(배경: 파스텔 그라데이션)
```

> 참고: 위 트리는 레이어 목록을 정리한 것이며, Figma 안의 실제 쌓임 순서(z-order)와 다를 수 있습니다. 자동화 스크립트는 순서가 아니라 **레이어 이름**으로 노드를 찾는 것을 원칙으로 합니다.

| 프레임 | 용도 |
| --- | --- |
| `card-01` | 1번 카드 |
| `card-02` | 2번 카드 |
| `card-03` | 3번 카드 |
| `card-04` | 4번 카드 |
| `card-05` | 5번 카드 |

### 네이밍 규칙

- 프레임 이름: `card-` + 두 자리 번호 (`card-01` ~ `card-05`)
- 레이어 이름: 소문자 + 하이픈(kebab-case)
- 자동화 스크립트가 이름으로 레이어를 찾으므로, **프레임·레이어 이름은 임의로 바꾸지 않습니다.**

## 4. 자동화 대상

### 4.1 현재 단계

| 레이어 | 처리 방식 |
| --- | --- |
| `title` | `slides.json`의 제목 값으로 텍스트 교체 |
| `body` | `slides.json`의 본문 값으로 텍스트 교체 |
| `source` | `slides.json`의 출처 값으로 텍스트 교체 |

### 4.2 추후 단계

| 레이어 | 처리 방식 (계획) |
| --- | --- |
| `main-image` | `slides.json`의 이미지 경로/URL을 받아 이미지 교체 |
| `page-number` | 필요 시 카드 순서에 따라 자동 생성 (예: `1/5`) |

### 4.3 고정 레이어 (자동화 제외)

- `bottom-overlay`
- 배경 (파스텔 그라데이션)

## 5. slides.json 데이터 연결 계획

> ⚠️ **주의: 아래 `slides.json` 구조와 필드명은 모두 가정(예시)입니다.**
> 실제 구조는 아직 확정되지 않았으며, 확정되면 이 문서를 함께 수정합니다.

### 5.1 예시 구조 (가정)

```json
{
  "series": "세모귀",
  "slides": [
    {
      "frame": "card-01",
      "title": "제목 예시",
      "body": "본문 예시입니다.",
      "source": "출처 예시 1",
      "image": "assets/character-01.png"
    },
    {
      "frame": "card-02",
      "title": "제목 예시",
      "body": "본문 예시입니다.",
      "source": "출처 예시 2",
      "image": "assets/character-02.png"
    }
  ]
}
```

### 5.2 필드 ↔ 레이어 매핑 (가정)

| slides.json 필드 (가정) | 대상 프레임/레이어 | 비고 |
| --- | --- | --- |
| `slides[n].frame` | `card-01` ~ `card-05` | 데이터를 넣을 프레임 지정 |
| `slides[n].title` | `title` | 현재 자동화 |
| `slides[n].body` | `body` | 현재 자동화 |
| `slides[n].source` | `source` | 현재 자동화. 필드명 `source`는 가정이며 미확정 |
| `slides[n].image` | `main-image` | 추후 자동화 |
| (없음) | `page-number` | 현재 고정. 추후 배열 순서로 생성 가능 |
| (없음) | `bottom-overlay` | 고정 |

### 5.3 연결 흐름 (계획)

1. `slides.json`을 읽습니다.
2. 각 항목의 `frame` 값(가정)으로 Figma 프레임(`card-01` ~ `card-05`)을 찾습니다.
3. 프레임 안에서 이름이 `title`, `body`, `source`인 레이어를 찾아 텍스트를 교체합니다. (`source` 레이어에는 `source` 값(가정)을 넣습니다.)
4. (추후) `main-image` 레이어의 이미지를 `image` 값(가정)으로 교체합니다.
5. 고정 레이어(`page-number`, `bottom-overlay`)는 건드리지 않습니다.
6. 결과물을 1080 × 1350 px 이미지로 내보냅니다.

### 5.4 확인 필요 사항

- [ ] `slides.json` 최종 필드명 확정 (출처 필드명 `source` 포함)
- [ ] `source` 값이 비어 있는 카드의 처리 방식 (레이어 숨김 / 빈 텍스트 유지)
- [ ] `source` 최대 글자 수 및 줄바꿈 규칙
- [ ] 프레임 지정 방식 확정 (`frame` 필드 사용 vs. 배열 순서 사용)
- [ ] `title` / `body` 최대 글자 수 및 줄바꿈 규칙
- [ ] 텍스트 교체 시 Jua / Gowun Dodum 폰트가 로드되는지 확인
- [ ] `main-image` 자동화 시 이미지 소스 형식 (로컬 경로 / URL)
- [ ] `page-number` 자동 생성 여부
- [ ] 카드 수가 5장이 아닐 때의 처리 방식
