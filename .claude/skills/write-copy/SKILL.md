# write-copy: outline.md → slides.json

카드에 실제로 들어갈 **문구**를 쓰는 단계다. 결과물 `slides.json`은 fill-figma가 그대로 읽어 피그마 템플릿에 넣는다. 규격은 `templates/layers.md` 5장을 따른다.

## 입력

- `projects/날짜_주제/outline.md`: **`상태: 승인됨`** 이어야 한다. 승인 대기면 진행하지 말고 승인부터 받으라고 안내한다.
- `projects/날짜_주제/brief.md`: 사실 확인과 출처용

## 문구 규칙

| 항목 | 규칙 |
| --- | --- |
| 제목 `title` | **20자 이내**(공백 포함). 한 카드의 핵심을 한눈에 |
| 본문 `body` | **80자 이내**(공백 포함). 1장 1메시지, 2~3문장 |
| 출처 `source` | **30자 이내**, `출처: `로 시작. 표지(card-01)는 `""`(빈 값 → 레이어 숨김) |
| 이미지 `image` | card-01만 `assets/characters/캐릭터명/cutout/` 아래 파일 경로. 없으면 `""`. 나머지 카드는 `""` |

- 글자 수는 **직접 세서** 확인한다. 넘으면 줄여서 다시 쓴다. 자르거나 말줄임표(…)로 끝내지 않는다.

## 세모귀 말투

- 친근하고 가벼운 말투. 친구에게 덕질 얘기하듯 쓴다. 기본은 **해요체**, 제목은 짧은 명사형·감탄형도 좋다.
- 이모지는 카드당 **최대 1개**. 없어도 된다.
- **사실은 brief.md에 있는 것만** 쓴다. 문구를 살리려고 사실을 부풀리거나 새 설정을 만들지 않는다.
- 태그 반영:
  - `[공식]`, `[2차 출처]` → 사실로 써도 된다.
  - `[팬 해석]` → "~라는 해석도 있어요", "팬들 사이에선 ~" 처럼 해석임을 드러낸다.
- outline에 `⚠️스포일러`가 있는 카드는 제목이나 본문 앞에 `⚠️스포 주의`를 넣는다.
- 금지: 특정 캐릭터·팬덤 비하, "역대급", "충격", "소름" 같은 낚시성 과장, 다른 작품과의 우열 비교.

### 좋은 예 / 나쁜 예

| | 제목 | 본문 |
| --- | --- | --- |
| 좋은 예 | 같이 본 시험, 결과는? | 하치와레랑 같이 본 풀뽑기 5급 시험. 그런데 합격자 명단엔 하치와레 이름만 있었어요. |
| 나쁜 예 | 충격! 치이카와 시험 대참사 | 치이카와는 너무 슬퍼서 며칠 동안 밤마다 울었다고 해요. (← brief에 없는 내용, 과장) |

## 절차

1. outline.md가 승인됨인지 확인한다.
2. 카드별로 outline의 핵심 메시지와 brief 항목을 보고 `title`, `body`를 쓴다.
3. `source`는 해당 brief 항목의 출처 ID를 출처 표에서 찾아 짧게 쓴다. 예: `출처: 위키백과(일본어)`, `출처: 나가노 X`
4. 아래 형식으로 `projects/날짜_주제/slides.json`을 쓴다(UTF-8).
5. **자체 검사**를 하고, 결과를 `projects/날짜_주제/copy-check.md`에 표로 남긴다.
6. 사용자에게 5장의 제목·본문을 표로 보여 주고, 검사 결과(통과/수정한 항목)를 알린다. 수정 요청이 오면 해당 카드만 고친다.

## slides.json 형식

```json
{
  "series": "세모귀",
  "topic": "치이카와 서사 정리",
  "character": "chiikawa",
  "slides": [
    { "frame": "card-01", "title": "...", "body": "...", "source": "", "image": "assets/characters/chiikawa/cutout/chiikawa-01.png" },
    { "frame": "card-02", "title": "...", "body": "...", "source": "출처: 위키백과(일본어)", "image": "" },
    { "frame": "card-03", "title": "...", "body": "...", "source": "출처: 위키백과(일본어)", "image": "" },
    { "frame": "card-04", "title": "...", "body": "...", "source": "출처: 위키백과(일본어)", "image": "" },
    { "frame": "card-05", "title": "...", "body": "...", "source": "출처: 위키백과(일본어)", "image": "" }
  ]
}
```

- `slides`는 정확히 5개, `frame`은 `card-01` ~ `card-05` 순서.
- 다섯 필드(`frame`, `title`, `body`, `source`, `image`)는 빈 값이어도 항상 넣는다.

## 자체 검사 (copy-check.md)

| 카드 | 제목 글자 수 | 본문 글자 수 | 출처 글자 수 | brief 근거 | 톤·금지어 | 결과 |
| --- | --- | --- | --- | --- | --- | --- |
| card-01 | 14/20 | 52/80 | 0/30 | - | OK | 통과 |

- 글자 수는 스크립트로 센다(예: `python -c "print(len('문구'))"`). 눈대중으로 세지 않는다.
- 하나라도 실패하면 고친 뒤 다시 검사한다. 최종 결과가 전부 통과일 때만 끝낸다.
